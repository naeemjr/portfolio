In progress Sole author2026

QXDP: Sub-Byte Packet Quantization and Runtime Bytecode Synthesis for Line-Rate Polymorphic DDoS Mitigation

An eBPF/XDP packet filter that uses compact sub-byte packet digests and runtime-generated bytecode to drop changing UDP DDoS floods at line rate without exhausting kernel lookup tables. Achieves 21.9 Mpps single-core drop throughput, 7.18 ms time-to-mitigate, and 0.0% false positives up to 40% payload mutation on Linux 6.18.

In progress Sole author2026

Refusal Under Uncertainty: Reproducible Benchmarks for Abstention in Security-Critical Systems

Studies when security tools should safely abstain instead of guessing on incomplete data, comparing Linux filesystem policy checks (PolicyContinuity) with encrypted QUIC traffic analysis (QUICScope).
